# Word of God Workshop (みことば工房)

Formerly Open Word Study. The web address and this repository keep the old name so that every link keeps working.

Free tools for reading the Greek New Testament and the Hebrew Old Testament more closely, built only from open data.
A side project and a work in progress. It is not affiliated with any Bible software company.

Live: https://vadneyk.github.io/open-word-study-site/

Sources and licences are in NOTICE.md. Pages that include unfoldingWord ULT, UST or Translation Notes content are shared
under CC BY-SA 4.0, as those sources require. Feedback is welcome through GitHub issues.

## Permanent links

People outside hold links to this site, so no page here may stop working. A page is never removed. If a page moves,
the old address stays as a redirect to the new one. The list and the check live in the source repository
(links.json, scripts/check_links.py, run by make check).
